# Suriname Spreekt: De Stem

Bouw een moderne webapp genaamd "Suriname Spreekt".

Het platform stelt Surinamers in staat om te stemmen op actuele maatschappelijke, economische en politieke stellingen.

De website moet een moderne, mobiele-first uitstraling hebben en vergelijkbaar aanvoelen als een combinatie van een nieuwswebsite en een social platform.

Taal standaard Nederlands, met een taalwisselaar voor Engels.

Hoofddoel: snel stemmen op actuele onderwerpen en direct de resultaten bekijken.

Gebruik een professionele uitstraling met de kleuren van Suriname als inspiratie, zonder overdreven gebruik van vlagkleuren.
